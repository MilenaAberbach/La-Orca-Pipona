# La Orca Pipona

Este repositorio contiene las distintas versiones del código desarrollado para el Proyecto Final Integrador de las materias Programación sobre Redes y Desarrollo de Sistemas.

## Versiones del proyecto

- **OrquitaPrograma_v1.zip:** primera versión del programa.
- **OrquitaPrograma_v2.zip:** segunda versión, con modificaciones y mejoras respecto a la anterior.
- **OrquitaPrograma_Final.zip:** versión definitiva del programa.

## Historial de desarrollo

Las distintas versiones permiten consultar la evolución del código durante el desarrollo del proyecto.

## Proyecto

La Orca Pipona es un robot autónomo diseñado para detectar y recolectar canicas.
